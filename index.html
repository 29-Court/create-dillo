dillo.

The backend that's hard to kill.

Dillo is a TypeScript backend framework for Cloudflare Workers. Your API is private by default. You declare exactly what is public, and auth fails closed.

npx create-dillo@alpha my-app
cd my-app
npm run dev

Scaffolding gives you a typed project with local dev. npm run check validates your application before it ships.

The CLI prints a random armadillo every time you run it. Zero dependencies.
